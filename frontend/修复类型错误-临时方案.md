# 修复类型错误 - 临时方案

## 方案 1：使用单独的类型声明文件（已创建）

已创建 `src/lucide-vue-next.d.ts` 文件，请重新运行构建：

```bash
npm run build
```

## 方案 2：如果方案 1 不起作用，跳过类型检查（临时）

修改 `package.json` 中的 build 脚本：

```json
"build": "vite build"
```

移除 `vue-tsc --noEmit &&` 部分。

**注意**：这会跳过类型检查，不推荐用于生产环境。

## 方案 3：使用 skipLibCheck（推荐）

在 `tsconfig.json` 中已经设置了 `"skipLibCheck": true`，这应该可以跳过库的类型检查。

如果问题仍然存在，可能需要清除缓存：

```bash
# 清除 node_modules 和重新安装
rm -rf node_modules package-lock.json
npm install

# 重新构建
npm run build
```
